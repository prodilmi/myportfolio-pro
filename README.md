# MyPortfolioPro

A professional, production-ready Portfolio Management System for stock investors.

## Features

- User authentication and security
- Portfolio management with multiple brokers (IBKR, XTB, etc.)
- Transaction tracking and analysis
- Interactive dashboard with charts
- Reporting and analytics
- Dividend tracking and watchlist
- Activity logging and audit trail

## Tech Stack

- **Backend**: PHP 8.3 (Native, no framework)
- **Database**: MySQL with PDO
- **Frontend**: Bootstrap 5, Vanilla JavaScript, Chart.js
- **Architecture**: MVC pattern (no framework dependencies)

## Installation

1. Clone the repository
2. Copy `config/database.php.example` to `config/database.php`
3. Update database credentials
4. Run the SQL schema
5. Access the application
